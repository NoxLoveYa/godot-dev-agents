## Checks

- Minimal check for every change: `<godot-exe> --headless --path <project> --import` after new scripts / assets, a clean
  log, and the area's headless tests once. Regression set: `& tools/<area>/regress.ps1` (serial; ~<n> min).
- Behaviour tests run with `--fixed-fps 60`. Tests never write `res://` or the player's `user://` files.
- Windowed runs (Movie Maker shots, perf, video): only when the owner asked or the work's result is a picture; the
  dispatcher warns the owner first (they can steal focus from a fullscreen app). Prefer `--headless`.
- Performance: measured only when the owner asks, with interleaved A/B in one process (`godot-performance`).
- The owner tests by hand; each delivery ends with a numbered hand-test list.
